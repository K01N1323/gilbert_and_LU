# Отчет по лабораторной работе №1: Сравнение методов решения СЛАУ

## 1. Постановка задачи
**Цель работы:** Реализовать набор функций для решения систем линейных алгебраических уравнений (СЛАУ) методом Гаусса и методом LU-разложения. Провести сравнительный анализ времени работы алгоритмов и продемонстрировать преимущество LU-разложения при решении систем с одинаковой матрицей, но разными правыми частями.

В рамках работы мною были выполнены следующие задачи:
* Реализован метод Гаусса без выбора ведущего элемента.
* Реализован метод Гаусса с частичным выбором ведущего элемента (по столбцу).
* Реализовано LU-разложение матрицы (с перестановками строк) и функции прямой и обратной подстановок.
* Проведено измерение времени работы алгоритмов на случайных матрицах разных размеров ($n$).
* Исследована эффективность LU-разложения при решении систем с множественными правыми частями ($k$).
* Проверена точность реализованных методов на плохо обусловленных матрицах (матрицах Гильберта) размерностей $n$.

## 2. Краткое описание реализованных алгоритмов
* **Метод Гаусса без выбора ведущего элемента:** Алгоритм прямого хода последовательно исключает неизвестные, приводя матрицу коэффициентов к верхнетреугольному виду. После этого я использую обратную подстановку для нахождения вектора решений. Метод уязвим к появлению нулей или очень малых чисел на главной диагонали.
* **Метод Гаусса с выбором ведущего элемента:** Модифицированная версия, в которой перед каждым шагом исключения я ищу максимальный по модулю элемент в текущем столбце и переставляю соответствующую строку на место ведущей. Это значительно повышает вычислительную устойчивость и снижает накопление ошибок округления.
* **LU-разложение (с перестановками):** Я представляю исходную матрицу $A$ в виде произведения нижней треугольной матрицы $L$ и верхней треугольной матрицы $U$ ($PA = LU$, где $P$ — матрица перестановок). Алгоритм использует выбор ведущего элемента для устойчивости. Решение системы $Ax = b$ сводится к решению двух треугольных систем с учетом вектора перестановок: сначала $Ly = Pb$ (прямой ход), затем $Ux = y$ (обратный ход). Трудоемкое разложение ($O(n^3)$) выполняется один раз, а поиск решения для вектора $b$ занимает $O(n^2)$.

## 3. Описание структуры программы
Программа написана на языке C++ с использованием объектно-ориентированного подхода:
* **matrixes** — класс, отвечающий за генерацию тестовых матриц (нормальное распределение, матрица Гильберта, единичная матрица).
* **default_gauss** — класс, в котором реализован классический метод Гаусса (строго без перестановок строк).
* **gauss_method** — класс с реализацией метода Гаусса с частичным выбором ведущего элемента.
* **LU_Decomposition** — класс для выполнения LU-разложения. Включает методы для декомпозиции (с перестановками строк) и последующего быстрого решения системы `SolveForTests()`.
* **tests.cpp / tests.h** — модуль с автотестами. Включает функции для замеров времени выполнения (через `std::chrono::high_resolution_clock`) и расчета норм невязки и относительной погрешности.
* **main.cpp / menu.cpp** — точка входа и консольное меню для удобного взаимодействия с функционалом лабораторной работы.

**Наблюдение:** LU-разложение в моей реализации работает быстрее остальных методов. Само решение (Solve) после завершения этапа разложения выполняется за доли миллисекунды (например, $0.000561$ сек для матрицы $n=500$).

## 5. Выводы
В ходе выполнения работы я пришел к следующим выводам:
1. **Эффективность LU-разложения:** Алгоритмическое разделение задачи на ресурсоемкую декомпозицию $O(n^3)$ и быстрый поиск решения $O(n^2)$ полностью оправдывает себя. При решении 100 систем для матрицы $n=500$ метод Гаусса затрачивает более 33 секунд, тогда как LU-разложение справляется с задачей за десятые доли секунды.
2. **Влияние выбора ведущего элемента:** На плохо обусловленных системах частичный выбор ведущего элемента несколько стабилизирует классический метод Гаусса, незначительно снижая погрешность при малых размерностях.
3. **Специфика плохо обусловленных матриц:** Тесты на матрице Гильберта наглядно продемонстрировали фатальную вычислительную неустойчивость. Даже алгоритмы, использующие выбор ведущего элемента (Гаусс с перестановками и LU-разложение с перестановками), быстро накапливают огромные погрешности. Уже при размере $n=15$ относительная погрешность достигает колоссальных значений, что говорит о том, что стандартная машинная арифметика двойной точности (double) не способна справляться со столь экстремально плохо обусловленными задачами без применения дополнительных методов регуляризации.
